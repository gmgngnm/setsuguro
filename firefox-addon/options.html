選んで訳す

ページの英文を選ぶか、英単語にカーソルを1秒あわせると、その場に日本語訳が出ます。

翻訳に使うもの どれか一つ。鍵はそれぞれ別に覚えているので、行き来しても入れ直しは要りません。
Gemini のAPIキー キーは Google AI Studio で作れます。この端末の中だけに保存され、訳す相手以外には送りません。
モデル 迷ったらそのままで構いません。キーを入れると、使えるモデルが候補に出ます。
DeepL のAPIキー DeepL API の認証キー。末尾が :fx の鍵は無料プランのものとして、無料版の宛先に送ります。
Google翻訳のAPIキー Google Cloud で Cloud Translation API を有効にしてから、認証情報 で作ったAPIキー。
動作
選んだときのふるまい
EnGoloyd の場所 英単語を一語だけ選んだときに出る「EnGoloydで開く」の飛び先。開いた先ではその単語の分解が始まります。
試してみる いま入っている設定のまま、短い英文を一つ訳します。
