# SaxChord — サックスのコード＆運指クイズ

サックスのソロ（アドリブ）練習のために、**コードの構成音を覚える → その場で運指を確認する → 実際に吹いて確かめる**までを 1 画面で回すための静的 Web アプリ。ビルド不要、`sax/index.html` を開くだけで動く。

## なぜ作ったか

既存のものは役割が分かれていて、管楽器奏者がいちばん詰まる「実音 ⇄ 記譜」の変換をまたいでくれない。

| 必要なこと | 既存の代表例 | 足りない点 |
| --- | --- | --- |
| コード構成音のクイズ | Chord Tone Training / ChordIQ / コードクイズ | 答えがピアノ鍵盤。E♭ 管の運指に繋がらない |
| 運指表 | Saxophone Fingering Chart など | クイズではなく引くだけ |
| 音程のマイク判定 | Saxophone Fingering Tuner ほかチューナー全般 | 「いま吹くべき音」と繋がっていない |

このアプリはその 3 つを 1 本に繋ぐ。

## できること

- **コード → 構成音**：コード名を見て 12 音から構成音をすべて選ぶ。
- **度数クイズ**：「B♭7 の ♭7 は？」をアドリブ中の速さで答える練習。
- **構成音 → コード名**：並んだ音からコード名を当てる。
- **運指クイズ**：運指図 → 音名、音名 → 運指の両方向。
- **吹いて答える（マイク）**：コードトーンを下から順に吹くと、マイクで音程を検出して 1 音ずつ ✓ が付く。
- **チューナー / 音当て**：吹いた音の実音・セント・その音の運指を表示。
- 答え合わせは**必ず運指図つき**。度数・記譜音・実音を並べて表示する。
- 苦手なコード／ルートほど出題されやすくなる（成績画面で確認できる）。
- 楽器は **アルト・テナー・ソプラノ・バリトン・C 管**。オフラインでも動く（PWA）。

## 実音と記譜

設定の「出題するコードの書かれ方」で切り替える。

- **記譜**：譜面に書かれたコードをそのまま吹く（移調済みのパート譜を想定）。
- **実音**：ピアノ譜・原曲キーで出題される。答えは**自分が吹く音**で答える。アルトなら実音 Cmaj7 → 記譜 A C♯ E G♯。セッションでピアノの譜面を渡されたとき用の訓練。

運指図はどちらのモードでも常に**記譜（実際に押さえる指）**で表示する。

## マイク判定について

- Web Audio API の生波形から NSDF（McLeod 法の簡易版）で基本周波数を推定する。サックスは倍音が強くオクターブを取り違えやすいので、自己相関のピークは「最大値の 0.85 倍を超える最初のピーク」を選ぶ。
- 判定はピッチクラス一致（オクターブは不問）＋ ±45 セント以内が約 0.2 秒続いたら合格。
- 基準ピッチは設定で変更できる（初期値 442Hz）。
- **HTTPS（または localhost）でないとマイクは使えない**。ブラウザの仕様。

## 運指データについて

低い B♭（記譜）からハイ F♯ までの標準運指を収録。よく使う代替運指（F♯ の右手薬指キー、B♭ の 1&1、サイド C、フロント F）はヒントとして併記している。

高音域は次のとおり（一般的なチャートに準拠）。

| 記譜音 | 運指 |
| --- | --- |
| ハイ D | オクターブ＋パーム D |
| ハイ E♭ | オクターブ＋パーム D・E♭ |
| ハイ E | オクターブ＋パーム D・E♭＋サイド E |
| ハイ F | オクターブ＋パーム D・E♭・F |
| ハイ F♯ | 上記＋ハイ F♯ キー（フロント F 系の代替あり） |

ハイ E・F はメーカーや個体、教える人によって「サイド E キーを足す／足さない」の流儀がある。息とアンブシュアで当たるなら、慣れた方でよい。

## 動かす

```sh
# リポジトリのルートで
python3 -m http.server 8000
# → http://localhost:8000/sax/
```

`sax/` を丸ごとどこかに置けば、そのまま静的サイトとして動く。

## テスト

`node test.mjs`（Playwright）で音楽理論・運指データ・ピッチ検出・各画面の操作を通しで検証している。
